agentscope

A graph of your agent network, live.

What it is

A graph of session clusters beside a repositories cluster, a sessions table and a detail pane, plus quota and guardrail tabs. It reads session metadata only, never a prompt or a response.

Install

go install github.com/go-agentsync/agentscope/cmd/agentscope@latest

Run

agentscope serve, then open http://127.0.0.1:8765/. It binds a loopback address and refuses any other. agentscope snapshot prints one snapshot in the terminal.

Recorded with agentscope capture --scenario theme-lang --out demo.svg: seven frames, vector, about 700 KB gzipped. For video-only platforms: the same demo as a WebM (--format webm, about 300 KB).
